# Changelog

Все значимые изменения в проекте CRM системы будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект следует [семантическому версионированию](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-XX

### Добавлено

#### Бэкенд
- FastAPI приложение с автоматической документацией
- JWT аутентификация с поддержкой ролей
- SQLAlchemy модели для пользователей, клиентов, сделок и задач
- CRUD API для всех сущностей
- Система логирования действий пользователей
- Поддержка SQLite и PostgreSQL
- Валидация данных с Pydantic схемами
- CORS настройки для фронтенда

#### Фронтенд
- React 18 приложение с современным дизайном
- Аутентификация с сохранением состояния
- Адаптивный интерфейс с Tailwind CSS
- Страницы для управления клиентами, сделками и задачами
- Поиск и фильтрация данных
- Формы с валидацией
- Уведомления о результатах операций
- Дашборд с общей статистикой

#### Развертывание
- Docker конфигурация для всех сервисов
- Автоматический скрипт запуска
- Создание тестовых данных
- Подробная документация

### Технические особенности
- Архитектура REST API
- Реактивные формы с React Hook Form
- Управление состоянием с React Query
- Типизированные API схемы
- Логирование всех CRUD операций
- Безопасное хранение паролей с bcrypt

### Безопасность
- JWT токены с истечением срока действия
- Хэширование паролей
- Валидация на уровне API и фронтенда
- Авторизация по ролям
- CORS защита
